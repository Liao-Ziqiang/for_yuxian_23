# Love Flows Within

送给 Yuxian 的 23 岁生日礼物。播放搭载的《Love Flows Within – Full Ensemble》，也可以点击页面拆开一句生日祝福。

## 改生日祝福

编辑 [wishes.txt](wishes.txt)，保持 UTF-8 编码，每行写一句。上传到 GitHub 后，Pages 会用更新后的列表。

## 在电脑预览

在项目目录运行 `python -m http.server 8000`，浏览器打开 <http://localhost:8000>。通过本地服务器预览时，网页会读取 `wishes.txt` 中的完整列表。

## 发布到 GitHub Pages

把文件提交到 `for_yuxian_23` 仓库的 `main` 分支。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，然后选择 `main` 和 `/(root)` 并保存。
